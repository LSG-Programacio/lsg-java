# Comparació amb LSG_0485_Java

Comparació feta el 22 d'octubre de 2026 amb [fconstanslasalle/LSG_0485_Java](https://github.com/fconstanslasalle/LSG_0485_Java), branca `master`, revisió [`a805dbd2b45050eb4f7ba328a67f5c7463b48ddc`](https://github.com/fconstanslasalle/LSG_0485_Java/tree/a805dbd2b45050eb4f7ba328a67f5c7463b48ddc). Els materials importats provenen d'aquest autor i repositori; els ajustos locals es descriuen a continuació.

## Criteri de comparació

S'ha inspeccionat l'arbre complet de l'origen (212 fitxers). A l'origen, el temari és dins de `src/`; aquí és a l'arrel. S'han comparat els continguts, no només els noms: s'han reconegut els canvis de paquets Java, salts de línia, espais i la ubicació diferent dels dos exemples bàsics de mètodes.

L'inventari inferior cobreix 150 fitxers de documentació, codi i recursos després de normalitzar noms i excloure configuració local o fitxers generats. Inicialment, 83 no tenien ruta equivalent, 45 coincidien exactament en Git i 22 tenien diferències. D'aquestes 22 diferències, 15 fitxers Java ja tenien el mateix codi amb ajustos de paquets o espais; els altres eren sis documents i `ObtenirRuta.java`, que estava buit.

## Adaptacions locals

- Es conserva l'organització numerada a l'arrel; no es crea una segona còpia del projecte dins de `src/`.
- Els exemples de consola nous no declaren paquet, seguint els exemples locals. Cada carpeta es compila independentment, especialment les que contenen una classe `Main`.
- `DemoMethodsHelloWorld.java` i `DemoMetodes1.java` es mantenen a `09_Java_Metodes/`. Els documents 09_07 i 09_08 apunten al codi existent.
- Els documents `README.md` i `readme.md` amb el mateix contingut a l'origen es tracten com un sol document, compatible amb Windows. Es mantenen els noms locals `read.md` i `readme.md`.
- Es corregeix l'apunt que deia que 20! desborda `long`: 20! cap i 21! desborda. La implementació didàctica original no es canvia.
- La documentació de Bobardino distingeix el codi bàsic present de les propostes d'ampliació de l'origen (TableView, múltiples vistes, etc.). No s'han implementat aquestes ampliacions.
- El codi Java preexistent, els POM, els recursos gràfics i els exercicis propis es conserven. L'únic fitxer Java preexistent modificat és el buit `ObtenirRuta.java`.

## Apartats que tampoc tenen programa a l'origen

- Hello World, variables primitives i condicionals es presenten com a fragments en Markdown.
- `13_Java_OPP/13_01_JavaClasses` aporta l'exemple de Persona dins del README, sense fitxer Java separat.
- `12_Java_Exceptions/11_02_DemoExceptions/main.java` està buit. S'incorpora l'explicació, sense atribuir-li un programa inexistent.

## Exclusions

No s'han importat `.idea/`, fitxers `.iml`, instruccions d'assistents ni el workflow de GitHub del repositori aliè: són configuració del seu entorn o infraestructura, no material docent. Tampoc es copien `target/` ni binaris compilats. La carpeta alternativa `15_JavaFX` només afegeix documentació i un FXML generat ja present entre els recursos del projecte Bobardino.

Els wrappers de Maven, POM, imatges i FXML de les carpetes equivalents ja existien i s'han contrastat amb l'origen. No s'han afegit dependències ni modificat remots, commits o configuració de Git.

## Validació i límits

La comprovació és [tests/ComprovarExemples.ps1](tests/ComprovarExemples.ps1), amb asserts a [tests/ProvesMetodes.java](tests/ProvesMetodes.java). Compila els 34 fitxers incorporats o completats i executa els 20 programes nous amb entrades conegudes. Comprova sumes, cerques, mitjanes, transposició, llistes, conversions, format i lletra del DNI, notes, recursivitat i comportament d'objectes. La compilació es fa en directoris temporals i no requereix dependències externes.

Resultat: correcte en els 34 fitxers, els 20 programes i els asserts de mètodes, amb JDK 20.0.2 i Windows PowerShell. També s'han comprovat els enllaços locals dels 57 documents Markdown i els delimitadors dels blocs de codi. Les aplicacions gràfiques i els exemples preexistents no s'han executat; els projectes JavaFX conserven els requisits dels POM (Java 17 a HelloWorld/demo i Java 21 a Bobardino).

Els programes importats conserven el comportament didàctic original. Molts assumeixen entrades numèriques correctes, dimensions positives i dades petites. El factorial no comprova el desbordament de `long` a partir de 21 i Fibonacci recursiu té cost exponencial; convé usar posicions petites. Les comprovacions cobreixen dades conegudes i límits bàsics dels mètodes, no constitueixen una auditoria completa de totes les entrades possibles.
