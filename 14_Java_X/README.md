# 14 - Java X (Projectes Avançats)

## Introducció

Aquesta carpeta conté projectes més complexos que integren diversos conceptes apresos en els mòduls anteriors. Són exemples pràctics que combinen programació orientada a objectes, gestió d'excepcions, interfícies gràfiques i altres tècniques avançades.

## Conceptes

### Integració de Conceptes
- Programació Orientada a Objectes
- Interfícies gràfiques d'usuari (GUI)
- Gestió d'esdeveniments
- Validació de dades
- Arquitectura de l'aplicació

### Disseny d'Aplicacions
- Separació de capes (presentació, lògica, dades)
- Patrons de disseny bàsics
- Organització del codi en packages
- Gestió d'estat de l'aplicació

### Interfícies Gràfiques
- Components Swing
- Layout managers
- Esdeveniments i listeners
- Validació d'entrada de l'usuari

## Exemples

### 13_01 - Calculadora Dora Exploradora
Exemple que demostra:
- Aplicació completa amb interfície gràfica
- Múltiples opcions i operacions
- Organització del codi en diferents classes
- Gestió d'esdeveniments d'usuari
- Validació d'entrada
- Càlcul i presentació de resultats
- Estructura de projecte amb packages

Aquest projecte integra:
- **OOP**: Classes i objectes ben estructurats
- **GUI**: Interfície gràfica amb Swing
- **Validació**: Control d'errors i entrada de dades
- **Modularitat**: Codi organitzat en mòduls reutilitzables

## Objectius d'Aprenentatge

- Aprendre a estructurar projectes grans
- Integrar diferents tecnologies i conceptes
- Desenvolupar aplicacions completes i funcionals
- Aplicar bones pràctiques de programació
- Gestionar la complexitat del codi

## Notes Importants

💡 **Consells per a Projectes Complexos**:
- Planificar l'estructura abans de començar a programar
- Dividir el problema en parts més petites
- Provar cada component de forma independent
- Documentar el codi adequadament
- Utilitzar noms descriptius per a classes i mètodes
- Aplicar els principis de la programació orientada a objectes
