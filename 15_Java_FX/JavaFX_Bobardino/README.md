# JavaFX_Bobardino

Aquest projecte conté una aplicació JavaFX bàsica amb FXML, un controlador i recursos d'imatge. Els apunts del repositori de referència també proposen components avançats per ampliar-la; no tots estan implementats en el codi actual.

## Conceptes

### Aplicació Completa
- Múltiples escenes o pantalles
- Interacció complexa amb l'usuari
- Gestió d'estat de l'aplicació
- Navegació entre vistes

### Components Avançats
- TableView per mostrar dades tabulars
- ListView per llistes
- ComboBox per seleccions
- Formularis complets

## Exemples

Aquest exemple demostra:
- Aplicació JavaFX completa
- Utilització de components avançats
- Gestió d'esdeveniments complexos
- Organització del codi en una app gran
- Bones pràctiques de JavaFX

## Notes Importants

💡 **Consells**:
- Estudiar l'estructura del projecte
- Comprendre la separació de responsabilitats
- Experimentar amb els components

## Estructura bàsica i ampliacions

Una aplicació hereta d'`Application`, construeix una `Scene` i la mostra en un `Stage`. Es poden explorar layouts com `VBox`, `HBox` i `BorderPane`, controls com `Button`, `Label` i `TextField`, gestors d'esdeveniments i estils CSS. Cal comprendre el cicle de vida i configurar el `module-path` quan no s'utilitza Maven.
